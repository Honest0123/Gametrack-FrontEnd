# 🎮 GameTrack

Aplicación web fullstack para gestionar una biblioteca personal de videojuegos.

## 🚀 Tecnologías

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express
- MongoDB Atlas
- Mongoose

## 🧠 Arquitectura

El frontend consume una API REST desarrollada en Express.

Frontend → HTTP → API REST → MongoDB Atlas

## ✨ Funcionalidades

- Visualización de videojuegos
- Filtrado por género
- Consulta por ID
- Creación de reseñas
